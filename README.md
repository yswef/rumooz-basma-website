# رموز بسمة للمقاولات
موقع PHP + SQLite متعدد الصفحات (الرئيسية، الخدمات، تفاصيل الخدمة، الأعمال، من نحن، تواصل، بحث) مع لوحة تحكم.

## التشغيل
1. ارفع المحتويات إلى `public_html` (يلزم PHP 8+ وإضافة pdo_sqlite وتفعيل mod_rewrite).
2. تأكد أن مجلدي `data` و`uploads` قابلان للكتابة.
3. افتح `/admin.php` وأنشئ كلمة المرور.
4. أضف صورك الحقيقية: انظر `assets/img/README.md` أو ارفعها من لوحة التحكم.

صُنع بحب من قبل [يوسف الحمزي](https://github.com/yswef)
