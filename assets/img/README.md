# مجلد الصور — ضع صور أعمالك الحقيقية هنا

سمِّ الصورة بالاسم المطلوب (jpg أو webp أو png) وسيظهرها الموقع تلقائياً بدل الصورة البديلة:

| الاسم | مكان الظهور |
|---|---|
| hero.jpg | خلفية الصفحة الرئيسية (أفقية، 1920×1080) |
| about.jpg | صورة "لماذا نحن" وصفحة من نحن |
| paint / renovation / decor / gypsum / insulation / floors / kitchens / maintenance (.jpg) | صور الخدمات الثمانية |
| work-1.jpg ... work-8.jpg | صور الأعمال (الرقم = رقم العمل) |

نصيحة: اضغط الصور قبل الرفع (أقل من 300KB للصورة، عرض 1200px يكفي) عبر squoosh.app.
أو ارفع صورة أي خدمة/عمل مباشرة من لوحة التحكم /admin.php وستأخذ الأولوية.
